# Teams and sharing

## Site members

The site owner can invite collaborators and remove existing members. Invitations are scoped to one site and accepted through the recipient's AnalyticsHQ account.

The hosted Free plan permits no additional teammates. Pro removes that teammate cap. A self-hosted installation has no billing gate.

## Public sharing

A site can expose a read-only public summary through its share setting. Public widgets, badges, and sparklines use separate endpoints so a site can embed a small metric without granting dashboard access.

Treat a share link as public information. Disable sharing when the intended audience changes.

## Ownership

Only the owner can change privacy-sensitive settings such as region collection, manage custom domains, delete the site's stored analytics, or delete the site itself.

## Data deletion

AnalyticsHQ supports deleting all data for a site and deleting a specific visitor's stored activity. These are destructive operations and should be used only after confirming the active site and identifier.
